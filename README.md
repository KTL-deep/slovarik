# Словарик

Нативное Android-приложение на Kotlin и Jetpack Compose. minSdk 26, target/compileSdk 35. Данные обучения хранятся локально в SQLite и доступны без сети. При первом запуске добавляются шесть демонстрационных английских слов; повторно примеры не создаются.

## Возможности

Интерфейс переработан по визуальному референсу: чёрный фон, лавандовый блок продолжения обучения, мятные папки, лимонные списки, коралловая практика и рисованные иконки нижней навигации. Поиск доступен в списках и карточках. Прогресс на главной странице рассчитывается из сохранённых данных, а не демонстрационных значений.

### Анимации

- Переходы между экранами с коротким смещением и затуханием; направление учитывает глубину навигации.
- 3D-переворот карточки при показе перевода (300 мс), без зеркального текста; в дереве доступности присутствует только видимая сторона.
- Появление следующего слова (180 мс), обратная связь при нажатии на папки/колоды, анимированные иконки нижней панели и прогресс.
- Цветовая обратная связь для правильного ответа, короткое смещение при ошибке в тесте, вводе и парах. Нет бесконечных декоративных анимаций.
- Используются штатные Compose API, учитывающие системный масштаб анимаций Android, включая значение `0`. Запись результата повторения не зависит от окончания анимации; защита от повторного нажатия срабатывает до записи.

В проект подключены навыки [`compose-animations`](https://skills.sh/chrisbanes/skills/compose-animations) (Chris Banes) и [`review-animations`](https://skills.sh/emilkowalski/skills/review-animations) (Emil Kowalski). Первый используется для нативных API, второй — для проверки принципов движения; веб-специфичные рекомендации не переносятся в Android буквально.

- Папки, колоды и карточки; добавление, исправление текста карточки без сброса прогресса и удаление с подтверждением; импорт списка из буфера вставки либо CSV/TSV через системный выбор файла (первые два столбца: слово, перевод; поддерживаются `;`, табуляция и CSV с кавычками).
- Повторение по **SM-2**, а не FSRS: карточка, выбор перевода из вариантов и ввод перевода. В режимах выбора и ввода неверный ответ всегда записывается как ошибка; после ответа нельзя сменить режим до оценки карточки. Прогресс и число дней занятий сохраняются.
- Отдельная кнопка «Тренироваться» доступна для любой непустой колоды: карточки, тест, ввод и сопоставление пар (раунды по 2–4 разных перевода). Тренировка **не меняет расписание SM-2, историю или статистику**; повторение по расписанию запускается только кнопкой «Повторить».
- Резервное копирование и восстановление полного набора данных и истории занятий в JSON через системный выбор файла. Восстановление **заменяет** текущие данные; при ошибке всё откатывается транзакцией.
- Произношение через установленный системный TTS. Автоперевод Google Translate через ML Kit (EN/RU/DE/ES/FR): модель скачивается **только при нажатии** «Скачать модель и перевести с Google»; при первом скачивании нужна сеть, после этого перевод доступен офлайн. Сохранённые слова не требуют ML Kit. [Документация и условия перевода](https://developers.google.com/ml-kit/language/translation/translation-terms), [Google Translate / Cloud Translation](https://cloud.google.com/translate).
- Ежедневное приблизительное напоминание через WorkManager; Android 13+ спрашивает разрешение на уведомления. Напоминание показывается, только если есть карточки к повторению.

## Сборка

На настроенном Windows-ПК дважды щёлкните **`Start Slovarik.cmd`**: он запустит эмулятор, соберёт и откроет приложение. Подробности — [ANDROID_EMULATOR.md](ANDROID_EMULATOR.md).

Требуются Android SDK 35 и JDK 21. Gradle 8.11.1 загружается включённым wrapper; SHA-256 дистрибутива закреплён в настройках. Укажите `ANDROID_HOME` либо `sdk.dir` в локальном `local.properties` (этот файл не включается в git).

`./gradlew :app:assembleDebug :app:testDebugUnitTest` (Windows: `gradlew.bat`)

APK: `app/build/outputs/apk/debug/app-debug.apk` — тестовая debug-сборка, не публикация для Google Play.

## Проверки

Проверены сборка, 7 JVM-тестов планировщика/импорта, Android Lint (без ошибок) и 7 тестов SQLite на Android 15: резервные копии, откат повреждённой копии, сохранение истории и прогресса при редактировании/перезапуске.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Тесты на устройстве запускайте **только на отдельном тестовом эмуляторе**: Gradle устанавливает и затем удаляет тестируемое приложение, что может удалить его данные.

```powershell
$env:ANDROID_SERIAL = 'emulator-5580'
.\gradlew.bat :app:connectedDebugAndroidTest
.\start-android.ps1 -NoBuild
```

Проверка через интерфейс (Python 3.11+, эмулятор запущен, приложение установлено):

```powershell
python .\tools\android_smoke.py
# Дополнительно: загрузка модели перевода и настройки напоминаний
python .\tools\android_smoke.py --services
```

UI-проверка использует демонстрационную колоду, отключает сеть на время проверки и восстанавливает её исходное состояние. Проверяются работа без сети, пары, независимость тренировки от расписания и сохранение результата после перезапуска. **Каждый запуск записывает одно настоящее повторение демонстрационной карточки.** Кадры сохраняются в `%LOCALAPPDATA%\Temp\opencode\slovarik-smoke`.

Расширенная проверка `--services` также прошла на установленном эмуляторе: Google Translate перевёл `book` в `книга`, затем новое слово перевелось без сети с сохранённой моделью; напоминания включаются и выключаются. После проверки напоминания выключены. Доставка уведомления в назначенное время отдельно не проверялась.

### Проверка редизайна без изменения пользовательского прогресса

`tools/android_redesign_smoke.py` делает кадры главного экрана, списков, словаря, режимов обучения, статистики и настроек. Он не оценивает карточки и сравнивает SHA-256 содержимого таблиц словаря и истории с исходным состоянием:

```powershell
# Перед обновлением интерфейса:
python .\tools\android_redesign_smoke.py --capture-baseline
# После установки новой сборки поверх существующей:
python .\tools\android_redesign_smoke.py
```

Проверка прошла на Android 15: данные словаря и повторений до и после обновления совпадают. Кадры и исходная контрольная сумма находятся в `%LOCALAPPDATA%\Temp\opencode\slovarik-redesign`. Android-тесты с переустановкой приложения для проверки редизайна не запускались, чтобы не удалять пользовательские данные.

### Проверка анимаций

После захвата исходного состояния и установки сборки:

```powershell
python .\tools\android_motion_smoke.py
```

Скрипт проходит те же экраны с масштабом системных анимаций `1`, затем `0`, проверяя неизменность данных. Исходные значения всех трёх системных масштабов восстанавливаются в `finally`; кадры сохраняются в `%LOCALAPPDATA%\Temp\opencode\slovarik-motion`. Обе проверки прошли на эмуляторе Android 15, как и сборка, JVM-тесты и Android Lint. Частота кадров и плавность на физическом телефоне не измерялись.

## Ограничения MVP

SM-2 использует интервалы в целых днях; сбой возвращается через день, не в рамках той же сессии. Планирование WorkManager неточное из-за энергосбережения. Импорт построчный: многострочные поля CSV не поддерживаются. Удаление папок и колод пока не реализовано. Для тренировки пар нужны минимум два разных перевода; если после разбиения остаётся одна карточка, в последнем раунде повторяется одна из предыдущих. Системный TTS зависит от установленных голосов. Загрузка моделей перевода требует Google Play services/совместимой среды и подключения к сети.
