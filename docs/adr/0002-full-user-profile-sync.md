# Полный сохранённый профиль вместо частичной синхронизации

Пользователь уточнил требование: между устройствами должны переноситься все сохранённые данные и прогрессы. Это расширяет границу ADR-0001: к словарю, расписанию и истории добавляются языки, случайное направление, настройка и время напоминаний, рекорды Match и последняя доступная отмена оценки.

Настройки объединяются независимо по ключам, а не одним большим документом; новые установки не отправляют незаданные значения по умолчанию поверх облачных настроек. Для рекордов Match применяется минимум времени, независимо от порядка доставки и локальных числовых ID колод. Возможность отмены связана со стабильными идентификаторами карточки и события; несовместимая отмена очищается версионированным состоянием, а не необратимой отметкой удаления.

SQLite остаётся источником сохраняемых данных; старые SharedPreferences используются как совместимое представление для интерфейса и Android-компонентов. Разрешения ОС, установленные голоса, токены входа, фоновые служебные маркеры и временное состояние открытого экрана не являются переносимыми данными профиля. Включённое напоминание переносит желание пользователя и время, но не выдаёт разрешение на уведомления на другом устройстве.
