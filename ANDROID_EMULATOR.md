# Android Emulator на Windows

Для проекта используется официальный Android Emulator с образом Android 15
(API 35, Google APIs, x86_64). Android Studio необязательна.

## Запуск приложения

Можно дважды щёлкнуть `Start Slovarik.cmd` в проводнике.
Либо из PowerShell в каталоге проекта:

```powershell
.\start-android.ps1
```

Скрипт запускает виртуальное устройство `Slovarik_API_35`, ждёт загрузки,
собирает debug APK, устанавливает его и открывает приложение. Первый запуск
сборки требует интернет для загрузки Gradle и зависимостей. Сохранённые данные
приложения остаются в эмуляторе между запусками.

Если PowerShell блокирует локальные скрипты, не меняйте политику всей системы:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-android.ps1
```

Для запуска уже собранной версии:

```powershell
.\start-android.ps1 -NoBuild
```

Эмулятор использует отдельный порт 5580. Скрипт не устанавливает приложение
на подключённый физический телефон.

По умолчанию используется программный рендеринг: при проверке аппаратный
рендерер сообщил ошибки импорта GPU-памяти. Для проверки другого режима:
`.\start-android.ps1 -Gpu auto`. Холодная загрузка не удаляет данные Android.

## Пути на этом ПК

- SDK: `C:\Users\KTL\AppData\Local\Android\Sdk`
- JDK: `C:\Users\KTL\AppData\Local\Java\jdk-21.0.12.1+1`
- Путь SDK для Gradle: `local.properties` (локальный файл, не для Git).

Скрипт учитывает `ANDROID_HOME` и `JAVA_HOME`. Глобальный `PATH` не меняется.

## Проверка оффлайн-режима

1. Создайте несколько карточек или импортируйте список.
2. В Android отключите Wi-Fi и мобильные данные.
3. Закройте и заново откройте приложение.
4. Проверьте списки, повторения и статистику.

Автоматический перевод и озвучка без сети зависят от заранее скачанных
языковых моделей и голосов. Это отличается от хранения слов: сохранённые
карточки доступны без сети независимо от наличия моделей.

## Если эмулятор не запускается

Проверка ускорения:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\emulator\emulator.exe" -accel-check
```

Для аппаратного ускорения нужна виртуализация AMD-V/VT-x в BIOS/UEFI и
поддерживаемый гипервизор Windows. Не отключайте средства безопасности
Windows для запуска эмулятора. Если обнаружена проблема графического
драйвера, можно отдельно попробовать программный рендеринг:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\emulator\emulator.exe" -avd Slovarik_API_35 -port 5580 -gpu software
```

Не запускайте два экземпляра одного AVD одновременно. Закрытие окна
эмулятора завершает виртуальное устройство, не удаляя его данные.
